# Gann Toolkit for TradingView

مؤشر Pine Script يرسم:

- زوايا جان الزمنية/السعرية: `1x1`, `2x1`, `1x2`, `3x1`, `1x3`
- مروحة جان إضافية
- نجمة جان بخطوط متناظرة
- اختيار تلقائي للقمة في الاتجاه الهابط أو القاع في الاتجاه الصاعد
- اختيار يدوي لنقطة الارتكاز بالوقت والسعر
- عرض النسب على الرسم
- مقياس ATR تلقائي أو مقياس يدوي للنقاط لكل شمعة

## طريقة الاستخدام

1. افتح TradingView ثم **Pine Editor**.
2. افتح ملف `Gann_Toolkit.pine` وانسخ محتواه إلى Pine Editor.
3. اضغط **Add to chart**.
4. في الإعدادات اختر `تلقائي` أو `يدوي`.
5. للمقياس الدقيق، اختر `يدوي` وأدخل عدد النقاط التي تمثل وحدة جان لكل شمعة؛ أو اتركه على ATR للتطبيع التلقائي.

> المؤشر أداة تحليلية، والنتائج تختلف حسب الأصل والإطار الزمني. اختبره قبل استخدامه في التداول الحقيقي.
